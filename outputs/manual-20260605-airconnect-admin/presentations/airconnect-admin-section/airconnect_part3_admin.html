관리자 페이지는
7개 운영 화면으로 구성됩니다

발표에서는 메뉴를 하나씩 누르는 방식으로 실제 서비스 운영 범위를 보여주면 자연스럽습니다.

대시보드

전체 가입자, 일간 활성 사용자, 매칭 성공, 티켓 지급·사용, 미처리 신고를 확인합니다.

회원 관리

회원 검색, 상태 확인, 상세 페이지 이동, 이용 제한·정지·탈퇴 상태를 관리합니다.

매칭 관리

매칭 연결 상태와 참여자 정보를 기준으로 수락, 대기, 거절 흐름을 추적합니다.

신고 관리

신고 상태와 신고자, 대상자 기준으로 신고를 조회하고 처리 단계를 변경합니다.

티켓 관리

유저별 티켓 보유량과 변동 내역을 조회하고 강제 지급·회수를 수행합니다.

공지·점검

전체 공지 발송과 서버 점검 모드를 관리해 서비스 운영 공지를 빠르게 반영합니다.
